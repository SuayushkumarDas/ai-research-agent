# 🤖 AI Research Agent

An intelligent **AI Research Assistant** built with **LangChain**, **arXiv API**, and **Ollama / OpenAI** that can:
- Search research papers from **arXiv**
- Read and summarize PDFs
- Act like a ChatGPT-style research chatbot
- Run **locally for free** using Ollama (no API cost)

---

## ✨ Features

- 🔍 **arXiv Paper Search** – find latest research papers by topic  
- 📄 **PDF Reader** – extract and analyze content from research PDFs  
- 🧠 **LLM-powered Agent** – reasoning + tool usage via LangChain  
- 💬 **Interactive CLI Chat** – ask questions like ChatGPT  
- 🆓 **Local Model Support (Ollama)** – no OpenAI quota needed  
- 🔄 **Fallback Handling** – graceful errors for API limits
